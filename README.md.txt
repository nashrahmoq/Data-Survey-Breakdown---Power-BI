# Data Survey Breakdown — Power BI

## Overview

This project is an interactive Power BI dashboard that analyzes survey
responses from data professionals.

The dashboard explores areas such as:

- Job titles
- Average salary
- Programming language preferences
- Difficulty of entering the data industry
- Salary satisfaction
- Work/life balance satisfaction
- Respondent demographics

## Tools Used

- Microsoft Power BI
- Power Query
- Data Cleaning
- Data Visualization
- Dashboard Design
- DAX
